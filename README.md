# Portal de Metas EPH

Portal interno do Esmeralda Praia Hotel: agenda e comprovação de treinamentos, equipe e checklist por função, blitz de conhecimento e gerenciamento do RH (Manual de Metas MNL-RH-02).

- Site: `index.html` (GitHub Pages)
- Banco: Supabase (`supabase/schema.sql` e `supabase/seed_modelos.sql`)
- A chave no código é a chave pública (publishable) do Supabase. O acesso aos dados é protegido por login e pelas regras de acesso (RLS) do banco.
